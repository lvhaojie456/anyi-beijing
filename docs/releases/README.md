## 写一份新记录

文件名 `YYYY-MM-DD-<主题>-<版本>.md`。至少写清：

1. 范围：代码版本与包含的 PR、Android 版本号、后端是否有迁移、制作端是否切换、环境变量是否变更。
2. 部署步骤与时间：备份产物文件名、服务器构建哈希与本机是否一致、暂存目录与回滚副本路径。
3. 验证：服务状态、健康检查、迁移记录行数、journal、Nginx 状态码、端到端验收（临时账号用完即删）。
4. 回滚：后端、制作端、安装包各自怎么回退。

线上 `/opt/anyiapp2/backend/RELEASE.json` 同步写入 `codeRevision`、`rollback` 与 `apkSha256`。
