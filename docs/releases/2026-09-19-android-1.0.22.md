## 回滚

```bash
sudo ln -sfn /var/www/anyi-downloads/anyi-memorial-1.0.21-release-v2.apk /var/www/anyi-downloads/anyi-memorial-latest.apk
sudo ln -sfn /var/www/anyi-downloads/anyi-memorial-1.0.21-release-v2.apk /var/www/anyi-downloads/anyi-memorial-release-latest.apk
```

后端无需回滚（本次未改后端）。1.0.22 的客户端改动只影响 UI 与本地缓存，回退到 1.0.21 后服务端接口仍向后兼容：`POST /ai/companions/:id/live2d/jobs` 的 `name` 字段在服务端是可选校验，旧客户端不传不会被拒。
