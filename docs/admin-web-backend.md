# 安忆 Web 管理后台

管理后台已从 Android App 内剥离，独立运行在腾讯云后端服务中：

```text
https://api.anyibj.cn/admin
```

## 登录

使用管理员账号登录。默认规则是用户名在 `ADMIN_USERNAMES` 中的账号拥有管理员权限，当前默认包含：

```text
admin
```

正式上线建议关闭“注册 admin 即管理员”的临时规则，改为手动初始化管理员或使用邀请码创建。

## 后台能力

- 社区内容：查看所有人文社区帖子，辅助运营和人工巡查。
- 义工信息：App 侧通过社区页按钮展示招募说明和联系方式。
- 上传审核：查看待审核素材，支持通过、拒绝、隔离。
- 账号注销申请：查看和更新注销请求状态。
- 崩溃日志：查看 Android App 上报的崩溃信息。
- 审计日志：查看管理员操作记录。
- 文件删除队列：统一处理待删除的本地上传文件。

## App 侧变化

Android App 主要作为用户端使用。管理员登录 App 后，会看到“管理功能已迁移到 Web 后台”的提示和入口，不再在 App 内处理运营审核。

## 后续建议

- 正式上线前改成独立后台域名，例如 `https://admin.your-domain.com`。
- 做更细的管理员权限分级，例如客服、审核员、财务、超级管理员。
- 给后台加双因素验证和登录失败锁定。
- 后台操作继续写入 `audit_logs`，保留追责能力。
