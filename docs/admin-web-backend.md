# 安忆 Web 管理后台

管理后台已从 Android App 内剥离，独立运行在腾讯云后端服务中：

```text
https://api.anyibj.cn/admin
```

## 登录

使用已由运维人员手动提升为管理员的账号登录。公开注册永远只创建普通用户，注册名为 `admin` 也不会获得管理员权限。

管理员初始化应通过受控的数据库运维流程完成，并在完成后移除临时提升权限；不要把管理员用户名或密码写进客户端。

在后端服务器上执行 `npm run admin:promote -- USERNAME` 可提升一个已经注册的账号。该命令只修改数据库角色，不接受或保存密码。

## 后台能力

- 订单管理：查看所有远程礼祭订单、确认付费、接单、开始处理。
- 验收上传：管理员上传验收图片，订单进入待用户确认。
- 订单沟通：管理员在后台给用户发送订单消息。
- 上传审核：查看待审核素材，支持通过、拒绝、隔离。
- 社区审核：处理待审动态和评论。
- 举报处理：保留、移除、驳回举报或屏蔽用户。
- 用户处置：解除屏蔽、查看封禁记录。
- 账号注销申请：查看和更新注销请求状态。
- 崩溃日志：查看 Android App 上报的崩溃信息。
- 审计日志：查看管理员操作记录。
- 文件删除队列：统一处理待删除的本地上传文件。

## App 侧变化

Android App 主要作为用户端使用。管理员登录 App 后，会看到“管理功能已迁移到 Web 后台”的提示和入口，不再在 App 内处理订单。

## 后续建议

- 正式上线前改成独立后台域名，例如 `https://admin.your-domain.com`。
- 做更细的管理员权限分级，例如客服、审核员、财务、超级管理员。
- 给后台加双因素验证和登录失败锁定。
- 后台操作继续写入 `audit_logs`，保留追责能力。
